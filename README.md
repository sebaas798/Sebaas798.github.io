# Sebastián Soba — sitio personal

Mi primera web de presentación como freelancer, publicada con GitHub Pages.

🔗 **Sitio:** https://sebaas798.github.io/

## Qué tiene

- **Hero** con mi nombre y lo que ofrezco: diseño, desarrollo web y testing de software, con base en Paysandú, Uruguay.
- **Mis servicios:** tres tarjetas (Diseño web, Testing de software y E-commerce).
- **Contacto:** formulario con nombre, teléfono, correo y mensaje (es solo maqueta: todavía no envía nada).
- Footer con derechos reservados.

Los textos de los servicios todavía son de relleno (lorem ipsum).

## Tecnología

- HTML y CSS puro, con `normalize.css` y la fuente Krub de Google Fonts.
- Hosting en GitHub Pages.

## Verlo localmente

Abrí `index.html` en el navegador.
